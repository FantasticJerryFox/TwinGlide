# Windows 原生界面设计

本次采用 [Anthropic frontend-design skill](https://github.com/anthropics/skills/tree/main/skills/frontend-design) 的设计规划与实屏复核流程。界面仍使用 WinForms，不增加浏览器或 WebView。

## 设计约定

- 双游是两台电脑之间的连接工具。设备身份、连接状态和屏幕关系优先于品牌装饰。
- 左侧固定导航，右侧显示当前设置；设备、屏幕、声音、个性化四页采用同一内容起点。保存操作固定在内容区底部，较小窗口只滚动设置内容。
- 8 像素间距节奏：页面边距 32，区段间距 24，表单行间距 8。标签列宽 176，所有输入控件共用同一纵向基线。尺寸均为 96 DPI 下的逻辑尺寸，由 WinForms 缩放。
- 字体使用 Microsoft YaHei UI，适合中文 Windows。正文 10 pt，区段标题 12 pt，页面标题 22 pt；说明使用同一字体，不用装饰性字体。
- 浅色语义颜色：画布 `#FFFFFF`、侧栏 `#F3F5F8`、文字 `#202B3A`、次要文字 `#586579`、分隔线 `#DCE2EB`、操作蓝 `#225DD2`。深色提供对应语义色，高对比度使用系统色。
- 蓝色用于当前导航和主要操作。屏幕预览突出键鼠来源；说明和状态都有文字，不仅依靠颜色。
- 保留原生输入框、下拉框、复选框、系统标题栏及键盘焦点。没有装饰动画，没有全屏内容背景图。

## 布局

```text
┌────────────────┬──────────────────────────────────────┐
│ TwinGlide 双游 │ 当前页面标题                         │
│                │ 连接状态                             │
│ 附近的设备     ├──────────────────────────────────────┤
│ 屏幕与键鼠     │ 页面说明                             │
│ 声音           │ 标签              输入控件           │
│ 个性化         │ 标签              输入控件           │
│                │ 双屏位置预览 / 当前声音流向          │
│ 本机昵称       ├──────────────────────────────────────┤
│                │ 操作反馈                 保存设置    │
└────────────────┴──────────────────────────────────────┘
```

设备发现、首次配对、已连接和离线使用同一布局。高级 IP 入口默认收起；普通用户从设备名开始。屏幕与声音的草稿独立保存，切换页面不提交或丢弃草稿。

采用固定侧栏与弹性内容区，是为了让各页字段和操作保持同一位置。没有采用四页各自居中或大小不一的按钮组合；视觉重点放在真实的双屏位置预览上。

实屏检查结果记录在 [VALIDATION.md](VALIDATION.md)。

高 DPI 使用 .NET Framework 4.7.2 的 `PerMonitorV2` 配置和 Windows 10 兼容性清单，遵循 [微软 WinForms 高 DPI 文档](https://learn.microsoft.com/en-us/dotnet/desktop/winforms/high-dpi-support-in-windows-forms)。构建会将配置文件与原生可执行文件一起打包；不修改用户系统缩放比例。
