# Mac 首次授权与连接排查

双游通过系统授权访问局域网和控制键鼠。应用不会自动授予自己权限，也不会改动其他共享软件的授权。

## 本地网络（macOS 15 及以上）

1. 两台电脑打开双游并连接同一局域网。
2. 在双游菜单栏或“设备与配对”点击“本地网络授权”，打开系统的“隐私与安全性”。
3. 进入“本地网络”，允许 **TwinGlide**；若同时列出 **TwinGlide Input**，也请允许。
4. 从双游菜单选择“退出双游”，再从 Finder 正常打开。已确认的配对会自动重连。

若原先已开启但连接仍报告无法访问局域网，可关闭再开启双游对应的开关，然后重新打开双游。
不要为了排查而关闭系统防火墙、修改隐私数据库或删除已有配对。

“能看到设备名称”不一定代表可以主动连接。本次实机测试中，Mac 能收到 Windows 的发现广播，
但应用主动连接失败；用户允许本地网络并重新打开后，加密连接恢复，随后完成真实键鼠跨屏。
网络不通也可能来自访客网络、设备隔离或防火墙，因此单凭 `No route to host` 不能认定是权限问题。

## 辅助功能

1. 在双游菜单栏点击“辅助功能授权”。
2. 在“系统设置 → 隐私与安全性 → 辅助功能”允许 **TwinGlide**；若列出 **TwinGlide Input**，也请允许。
3. 如果列表没有双游，可通过系统的添加按钮选中已安装的 `TwinGlide.app`，然后允许它。
4. 双游会自动重试；仍不生效时，从菜单退出后重新打开。

两种键鼠来源都需要 Mac 的辅助功能授权：Mac 提供键鼠时用于捕获操作，Windows 提供键鼠时用于接收操作。
“已配对”只表示两台电脑建立了信任，不表示系统已经允许键鼠控制。

## 系统声音

仅在 Mac 向另一台电脑转发声音时，需要系统音频／屏幕录制授权。
可从双游菜单栏的“系统声音授权”进入。双游不会采集麦克风。

## 开发构建与公开发行

当前 Mac 包使用临时签名，更新开发构建后系统可能要求重新确认授权。
正式公开发行应采用 Apple 签发的 Developer ID 进行稳定签名与公证。
登录启动项通过 `AssociatedBundleIdentifiers` 关联双游，输入辅助应用也包含局域网用途说明。
实测权限行为及尚未覆盖的环境见 [验证记录](VALIDATION.md)。

实现依据：[Apple TN3179：Understanding local network privacy](https://developer.apple.com/documentation/technotes/tn3179-understanding-local-network-privacy)。
